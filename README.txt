- assets/logo.png

## Free publishing
The easiest free option is GitHub Pages:
1. Create a free GitHub account.
2. Create a new public repository.
3. Upload all files/folders from this package.
4. Open Settings -> Pages.
5. Select "Deploy from a branch", choose the main branch and root folder.
6. Save. GitHub will provide a free website address.

You can also upload the same files to other static hosting services.

## Important
Update phone, email, destinations, wording or links in `index.html` whenever needed.
